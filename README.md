🌸 # **MandalaMuse – E-Commerce Website for Mandala Art**  

📌 ## Project Overview

MandalaMuse is a full-stack e-commerce web application designed for showcasing and selling mandala art products such as paintings, digital designs, and customized artwork. The platform provides a smooth and user-friendly shopping experience while promoting aesthetic and traditional mandala art in a digital format.

This project is built using the MERN stack (MongoDB, Express.js, React.js, Node.js) and demonstrates complete full-stack development, including frontend, backend, database, and third-party integrations.

🚀 Features
🔐 User Authentication (Login & Signup using JWT)
🛍️ Product Browsing and Search
🛒 Add to Cart and Cart Management
💳 Checkout Functionality
👤 Role-Based Access Control (Admin/User)
🖼️ Image Upload using Cloudinary
📱 Fully Responsive UI (Mobile + Desktop)
⚡ Fast and Dynamic UI with React

🏗️ Project Architecture

The project follows a client-server architecture:

The frontend (React.js) handles the user interface and user interactions.
The backend (Node.js + Express.js) manages APIs and business logic.
The database (MongoDB) stores user data, product details, and order information.
The frontend communicates with the backend using REST APIs.

📂 Key Functional Modules
1. User Module
User registration and login
JWT-based authentication
Role-based access (Admin/User)
2. Product Module
Add, update, delete products (Admin)
View product details
Product listing and filtering
3. Cart Module
Add/remove items from cart
Dynamic price calculation
4. Order Module
Place orders
Store order details


⚙️ Installation & Setup
# Clone the repository
git clone https://github.com/your-username/mandalamuse.git

# Navigate to project folder
cd mandalamuse

# Install backend dependencies
cd backend
npm install

# Install frontend dependencies
cd ../frontend
npm install

# Run backend server
cd ../backend
npm start

# Run frontend
cd ../frontend
npm start
